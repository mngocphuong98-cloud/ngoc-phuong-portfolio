# Ngọc Phương — Work & Knowledge Portfolio

## Mở website
Mở file `index.html` bằng Chrome/Edge. Website là file tĩnh, không cần cài đặt gì.

## Nội dung V1
- Hero / định vị nghề nghiệp
- About & cách giải quyết vấn đề
- 6 case study
- SAP Knowledge Base
- Toolkit / kỹ năng
- Responsive cho desktop và mobile

## Nên bổ sung ở V2
1. Ảnh chân dung chuyên nghiệp hoặc ảnh workspace.
2. Ảnh dashboard/file kiểm soát đã làm mờ dữ liệu nhạy cảm.
3. Mỗi case study có 1 trang riêng.
4. CV PDF và LinkedIn.
5. Email liên hệ.
6. Song ngữ Việt/Anh nếu dùng để ứng tuyển công ty quốc tế.

## Nguyên tắc bảo mật
Không đăng tên khách hàng/NCC nội bộ, số tiền nhạy cảm, mã tài sản, mã PO/SO, ảnh màn hình SAP có dữ liệu thật nếu chưa che thông tin.
