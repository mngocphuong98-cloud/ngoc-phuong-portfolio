# Portfolio Design System

## Design direction

Professional Production Accounting / SAP knowledge portfolio.

Design dials:
- Variance: 6/10
- Motion: 4/10
- Density: 5/10

## Audience priority

1. Finance / Accounting hiring manager
2. SAP / process-improvement manager
3. Recruiter
4. Professional peer reading the Knowledge Base

## Visual principles

- High trust over visual spectacle
- Modern sans typography
- One accent family
- Clear content hierarchy
- Strong technical readability
- Asymmetry used with restraint
- Responsive by design, not by shrinking desktop

## Information hierarchy

Homepage priority:
1. Positioning
2. Professional thinking
3. Expertise
4. Selected case studies
5. SAP Knowledge Base
6. Learning / working system
7. Contact / next step when available

## Breakpoints

Use these as practical checkpoints:
- small mobile: 360px
- common mobile: 390px
- tablet: 768px
- laptop: 1024px
- desktop: 1280px+

## Accessibility

- semantic HTML
- visible keyboard focus
- adequate contrast
- touch targets around 44px where possible
- reduced-motion support
- readable font sizes on mobile
- no essential information conveyed by color alone

## Content tone

Specific, calm, evidence-based.

Avoid:
- exaggerated self-promotion
- invented metrics
- generic buzzwords
- unexplained SAP acronyms
- confidential business details
