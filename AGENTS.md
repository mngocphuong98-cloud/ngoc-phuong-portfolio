## Product intent

Audience:
- Finance / Accounting hiring managers
- Production Costing teams
- SAP Key User / Process Improvement teams
- Recruiters evaluating structured problem-solving capability

Positioning:
- Production Accounting
- SAP FI / CO / MM / AA
- Costing & month-end controls
- Reconciliation & root-cause analysis
- Data mapping / Excel / Google Sheets / automation

The portfolio must demonstrate how problems are understood and controlled, not merely list transaction codes.

## Core design settings

- DESIGN_VARIANCE: 6/10
- MOTION_INTENSITY: 4/10
- VISUAL_DENSITY: 5/10
- Mobile-first
- High-trust, modern, calm, structured
- One primary accent color
- No generic AI-purple gradients
- Avoid decorative effects that reduce readability

## Non-negotiable behavior

Preserve and test:
- Vietnamese / English language switch
- Mobile navigation
- SAP Knowledge Base search
- SAP Knowledge Base filters
- Expand/collapse notes
- Keyboard focus visibility
- Responsive layouts without horizontal overflow

## Confidentiality

Never publish real confidential business information unless explicitly approved:
- customer/vendor names
- internal company names
- PO/SO numbers
- asset numbers
- sensitive amounts
- real SAP screenshots containing identifiable business data
- internal account mappings when not appropriate for public disclosure

Generalize examples and use synthetic values where examples are needed.

## Change discipline

For redesigns:
1. Audit first.
2. Identify what already works.
3. Make focused changes.
4. Preserve functionality.
5. Check desktop and mobile.
6. Check VI and EN.
7. Re-test search/filter/menu behavior.
8. Do not call work complete without confirming the deployed page.
