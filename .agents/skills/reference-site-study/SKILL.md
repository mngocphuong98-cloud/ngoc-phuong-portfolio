# Reference Site Study Skill

Use this when the user provides a website and asks to make the portfolio feel similar.

The goal is to learn the design system and interaction patterns, not to impersonate or reproduce another brand.

## Workflow

### 1. Map
Record:
- reference URL
- relevant pages/sections
- which portfolio section the reference informs

### 2. Observe
Inspect desktop and mobile.

Capture the rules behind:
- page width
- grid
- typography scale
- spacing rhythm
- navigation behavior
- color system
- section transitions
- responsive changes
- hover/click/scroll interactions

Do not infer a rule from a single screenshot if multiple viewport states matter.

### 3. Translate
Rebuild the underlying design logic using:
- Ngọc Phương's own content
- the portfolio's own color system
- the portfolio's own branding
- generalized business examples

Do not copy:
- logos
- proprietary illustrations
- brand copy
- private assets
- distinctive trademark presentation

### 4. Compare
Compare reference intent with the new portfolio at matched viewport sizes.

Fix in this order:
1. geometry and hierarchy
2. typography
3. spacing
4. responsive behavior
5. interaction
6. subtle visual polish

### 5. Validate
Check:
- mobile
- desktop
- VI/EN
- all existing portfolio functionality
- production deployment
